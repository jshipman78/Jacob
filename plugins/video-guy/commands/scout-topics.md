# Scout topics

Dispatch the `history-topic-scout` agent. Theme or constraint: `$ARGUMENTS`
(no argument means an open search).

Require of the scout:

- **Search, do not recall.** The value of a scout is bringing back what the
  channel has not already thought of. A list of famous anecdotes is a failed run.
- 5–10 candidates, each as a full scouting card: `hook_score`, `visual_score`,
  `story_score`, `research_depth`, `estimated_runtime`, `angle`,
  `title_candidates`, `imagery` (named institutions), `myths_to_kill`, `risks`.
- Rejections stated out loud, with reasons — a topic with no surviving imagery
  is more useful named than omitted.
- One recommendation, not a hedge across all ten.

Present the ranked list, then ask which to greenlight. **Do not create a
production** — that is `/new-video`, and it is the user's call.
