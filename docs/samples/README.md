# Sample output

`the fall of Carthage`, produced end to end by `npm run make-video -- "the fall of Carthage" --minutes=5`
on 2026-08-07. Committed so the pipeline's actual output can be judged without
running it (a full run costs roughly $7 and 90 minutes).

- `carthage-transcript.md` — the narration, with timecodes measured from the audio.
- `carthage-citations.md` — every claim, its verdict, the falsification attempted
  against it, its sources, and the timecode it is spoken at.

Worth reading in the citations file: **C3**, where the adversarial fact-check
found a 1299 papal bull and a 2023 conference paper on medieval Maghrebi
folklore that together undermine the tidy "the salted-earth story is a
19th-century invention" line, and forced the narration to say so out loud.
